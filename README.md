# Prerequierements

the project is main focused using uv. uv is a package and project python manager thinked to be fast. To see how it could be installed see [this](https://docs.astral.sh/uv/#highlights) link or just run the next code:

linux/macOS:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

windows:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

to install the dependencies just run:

```bash
uv sync
```

the main dependencies are:

- astropy

- matplotlib

- numpy
